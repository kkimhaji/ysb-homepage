# 이미지 폴더 안내

## 1) 히어로(첫 화면) 배경 사진
연세대를 상징하는 사진(예: 언더우드관, 백양로, 경영관)을 넣고 싶으시면
가로 2000px 이상 JPG 파일을 아래 이름으로 저장하세요.

    assets/img/hero.jpg

그리고 `assets/css/site.css` 의 `.hero__photo` 규칙에서
`--hero-photo` 값을 아래처럼 지정하면 됩니다. (site.css 맨 아래에 이미 주석으로 준비되어 있습니다.)

    .hero{ --hero-photo:url("../img/hero.jpg"); }

사진을 넣지 않으면 직접 제작한 건물 라인아트 + 공급망 네트워크 그래픽이 그대로 보입니다.

## 3) 공식 로고 (brand 폴더)
`brand/` 폴더에는 연세대학교 경영대학 공식 로고가 들어 있습니다. 헤더와 푸터에서 자동으로 사용되며
교체할 일은 없습니다. 비율이나 색을 임의로 바꾸지 마세요.

## 저작권 주의
학교 공식 사진이라도 외부 공개용 홈페이지에 쓰기 전에는 홍보팀 또는 촬영자에게
사용 허락을 받아 두시는 편이 안전합니다.
